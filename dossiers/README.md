- `dossiers/finance/tax/` — IRS Form 8949 / Schedule 1 tax ledgers, provenance traces, and PGP-sealed compliance bundles
- `dossiers/threat_intel.md`, `dossiers/finance_intel.md`, `dossiers/hardware_deals.md` — Domain OSINT sweeps
