# Recall Seed — Default Knowledge Base

## Common Patterns
- Research tasks: /web search <keywords> → /web fetch <url> → /write summary
- Code tasks: /init <name> <type> → /write files → /build → /test → /fix
- Communication: /email, /social post, /phone
- File operations: /write <path> <content>, /edit <path>, /save, /append
- Version control: /git status → /commit → /push

## Troubleshooting
- If a command returns "Usage:" text, check argument syntax
- If /build fails, read the error output and use /fix or /edit
- If /web fetch returns junk, try a different URL or /web search for alternatives
- If stuck in a loop, try a completely different command or approach

## Task Types
- abstract: Research, brainstorm, analyze — use /web search, /recall, /journal
- concrete: Build, write, create — use /init, /write, /build, /test
