3. Production Migration: Moving Beyond Sandbox

              
To deploy permanent production sentinels:

              
    
                
  • Private API Keys: For authenticated APIs (Binance, Twitter, Bloomberg), store credentials in .george/secrets.env and reference them in custom trigger action scripts via ${SECRET_VAR}.
    • 
                
  • Daemonization: All triggers launched via the UI run as managed background jobs. To run them as system-level services, configure a systemd unit targeting lib/tools/event_router.sh so the bus runs continuously across server reboots.
    • 
                
  • Persistent Watchers: Set SearXNG queries in .george/osint_watchers.yaml to point to a production SearXNG instance URL (e.g. your private homelab SearXNG at http://192.168.1.20:8888).
