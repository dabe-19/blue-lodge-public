MODES & MOTIONS

            

              i / a
              Enter INSERT mode to type text
            

            

              Esc
              Return to NORMAL command mode
            

            

              gg
              Jump to line 1 (start of file)
            

            

              G
              Jump to last line (end of file)
            

            

              gf
              Go to file: jump to referenced script/module under cursor
            

            

              gt / gT
              Next tab / Previous tab buffer
            


            
LINE & CLIPBOARD

            

              dd
              Delete entire current line
            

            

              yy
              Yank (copy) current line to system clipboard
            

          


          

            
EX-COMMANDS (:)

            

              :w / :w!
              Save active buffer (validates via bash -n)
            

            

              :q
              Quit active buffer (blocks if modified)
            

            

              :q!
              Force quit active buffer without saving changes
            

            

              :wq / :x
              Save buffer and close tab
            

            

              :bd / :bd!
              Buffer delete (close tab / force close tab)
            

            

              :qa / :qa!
              Quit all tabs & exit editor / Force quit all
            

            

              :tabnew
              Open a new blank script buffer
            

            

              :e <path>
              Open specified file path in new tab

              Change delimiter: replace "foo" with 'foo' via cs"'
            

            

              ds<char>
              Delete delimiter: strip quotes from "foo" via ds"
            

            

              ysiw<char>
              Surround inner word: wrap current word in "...", (...)
